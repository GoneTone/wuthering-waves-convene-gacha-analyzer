## 重要執行須知

- **遷移期間整體 compile 會短暫紅燈**：03 起替換核心型別（GachaRecord 等欄位），其消費端到 04–07 才補齊。**全專案 `flutter analyze` 全綠由 plan07 最後一個 Task 收尾**。各 plan 內純新增檔（`record_merge`、`gacha_credential`、`item_image_*`）可獨立 TDD；但跨檔型別替換的 plan（03/05）在後續 plan 完成前，`flutter test` 可能因 compile error 無法整體跑——以該 plan 自身單元測試 + 註明的整合點為準。

- **不得殘留原神名詞**（spec D10）：crate `gacha_capture_core`、CA subject、`item_image_*`、installer 新 AppId `{27F3CD23-7E15-4570-8EBB-79D2801C9C85}`（與原神版並存不覆蓋）。
