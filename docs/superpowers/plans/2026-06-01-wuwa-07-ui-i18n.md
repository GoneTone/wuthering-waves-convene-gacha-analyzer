# UI Pages & i18n Finalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** 將所有 UI 頁面與元件從「原神祈願 + 頌願雙段」資料模型收斂為「鳴潮 8 卡池單段喚取」模型，移除 2★／頌願／HoYoWiki 外連，補上第三物品類型「道具」與 8 卡池側欄/配色，並完成 ARB i18n 收尾。

**Architecture:** 此 plan 屬遷移系列的 UI/i18n 收尾（spec §F、§G 與 P1/P2/P3）。下游消費 plan 03（`gacha_types` 8 筆 cardPoolType、移除 `GachaCategory`）、plan 05（`GachaStats` 移除 2★、`GachaRecord.qualityLevel/resourceId/resourceType/cardPoolType`、`overview_sections` 單段、`item_type_kind` 加道具）、plan 06（`item_image_*` 取代 `hoyowiki_*`、`hasItemImage`）。本 plan 只改 UI 層 widget／page 與 ARB，不動資料層/服務層型別本身。

**Tech Stack:** Flutter (Material 3 + Riverpod + go_router)、Dart gen-l10n（4 ARB：zh/zh_Hans/en/ja）、`fl_chart` Pie。

> **重要前置認知（整個遷移期間）：** 此遷移是一連串 plan，型別替換期間整體 compile 可能短暫紅燈，須 plan 03/05/06 全部就位後本 plan 才能 `flutter analyze` 全綠。本 plan 內所有 Task 都假定 plan 03/05/06 的跨 plan 介面契約（檔首列出的確切名稱）已落地。若執行本 plan 時上游尚未完成，請先完成上游或在 worktree 內以上游契約 stub 補齊。**本專案目錄非 git repo**：commit 步驟照寫；若執行者未 `git init`，commit 步驟略過即可（仍須跑完三項品質檢查）。

  /// preload 流程的 logger。
  final _log = Logger('gacha.itemimage.preload');

  /// 提供分享圖 sync pipeline 用的預解碼 icon [ui.Image] map（key = resourceId）。
  class PreloadedItemImages extends InheritedWidget {
    /// 建立 [PreloadedItemImages]。
    const PreloadedItemImages({
      super.key,
      required this.images,
      required super.child,
    });

    /// resourceId → 預解碼的 [ui.Image]（已 owned；render 結束需 dispose）。
    final Map<int, ui.Image> images;

    /// 從祖先 [PreloadedItemImages] 取得；不存在回 null。
    static PreloadedItemImages? maybeOf(BuildContext context) =>
        context.dependOnInheritedWidgetOfExactType<PreloadedItemImages>();

    @override
    bool updateShouldNotify(PreloadedItemImages oldWidget) =>
        !identical(images, oldWidget.images);
  }

  /// 預解碼 [records] 對應的角色 icon cache 檔成 [ui.Image] map（key = resourceId）。
  ///
  /// 只預載 icon（illustration 體積大不進 preload）。缺 cache 或無 icon 的
  /// record 直接跳過（分享圖內走 placeholder）。回傳的 map 須由 caller 在 render
  /// 結束後呼叫 [disposePreloadedItemImages] 釋放 native 資源。
  Future<Map<int, ui.Image>> preloadItemImages({
    required ItemImageIndex index,
    required Directory cacheDir,
    required Iterable<GachaRecord> records,
  }) async {
    final out = <int, ui.Image>{};
    final seen = <int>{};

    for (final r in records) {
      if (!seen.add(r.resourceId)) continue;
      final entry = index.lookupImage(r.resourceId);
      final url = entry?.iconUrl;
      if (entry == null || url == null || url.isEmpty) continue;
      final file = itemIconCacheFile(
        baseDir: cacheDir,
        resourceId: r.resourceId,
        url: url,
      );
      if (!file.existsSync()) continue;
      try {
        final bytes = await file.readAsBytes();
        final codec = await ui.instantiateImageCodec(bytes);
        final frame = await codec.getNextFrame();
        codec.dispose();
        out[r.resourceId] = frame.image;
      } catch (e, st) {
        _log.warning('preload decode failed rid=${r.resourceId}', e, st);
      }
    }
    return out;
  }

  /// dispose 由 [preloadItemImages] 產出的所有 [ui.Image]。
  void disposePreloadedItemImages(Map<int, ui.Image> images) {
    for (final img in images.values) {
      img.dispose();
    }
  }
