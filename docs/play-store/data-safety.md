# 資料安全表單建議答案

Play Console →「應用程式內容」→「資料安全」。以下是依 App 實際行為整理的建議，**送出前請自行確認**。

Play 的「收集」指的是 App 把資料傳出裝置（不論傳給開發者還是第三方）；「分享」指的是傳給第三方。玩家自己觸發、且預期會傳送的情況（例如玩家按下同步），不算「分享」。

## 總覽題

| 問題 | 建議答案 | 理由 |
|---|---|---|
| App 是否收集或分享任何必須揭露的使用者資料？ | 是 | 查詢喚取紀錄時會把 UID 等參數傳給遊戲官方伺服器；雲端同步會把紀錄傳到 Google 雲端硬碟 |
| 收集的資料是否都在傳輸時加密？ | 是 | 所有連線都是 HTTPS |
| 使用者能否要求刪除資料？ | 是 | 資料只在裝置與玩家自己的雲端硬碟；App 內可刪除帳號（可勾選一併刪除雲端資料），解除安裝會刪除裝置上的資料（Android 系統備份的副本由玩家在自己的 Google 帳號管理） |

## 資料類型

| 類型 | 收集 | 分享 | 用途 | 必要或選用 | 理由 |
|---|---|---|---|---|---|
| 個人資訊 → 使用者 ID | 是 | 否 | 應用程式功能 | 必要 | 鳴潮 UID 隨查詢參數送到遊戲官方伺服器，是玩家觸發的查詢 |
| 個人資訊 → 電子郵件地址 | 是 | 否 | 應用程式功能、帳戶管理 | 選用 | 只在玩家連結雲端同步時，從 Google 取得 email 顯示目前連結的帳號 |
| 應用程式活動 → 其他使用者產生的內容 | 是 | 否 | 應用程式功能 | 選用 | 雲端同步把喚取紀錄寫入玩家自己的 Google 雲端硬碟 |

## 不需要勾選的項目

- 當機紀錄、診斷資料：log 只在玩家自己匯出或分享時才離開裝置，屬於玩家觸發的傳送。
- 位置、聯絡人、相片、檔案：不收集。玩家自己選擇匯入的檔案只在本機讀取。
- 廣告 ID：沒有使用。
- Android 系統備份：App 資料（喚取紀錄、設定）可能由 Android 的系統備份存到玩家自己的 Google 帳號，是否備份由玩家的裝置備份設定決定，開發者收不到。加密保存的憑證（`flutter_secure_storage`，例如無線偵錯的配對金鑰）已用 `backup_rules.xml`／`data_extraction_rules.xml` 排除。

## 待確認

- 「使用者 ID」是否算「收集」：資料是傳給遊戲官方而不是開發者，Play 的定義包含傳給第三方，所以這裡保守填「是」。如果審查回覆可以不填，再改。
