# 商店頁文字

Play Console →「主要商店資訊」。預設語言為繁體中文（台灣），另外新增英文（美國）、日文、簡體中文三種翻譯。

字數上限：App 名稱 30 字、簡短說明 80 字、完整說明 4000 字（Play 以字元計，中日文一個字算一個字元）。

> 英文標題原本設計為「Convene Analyzer for Wuthering Waves」，但它有 36 個字元，超過 30 字的上限，所以改用遊戲常見的縮寫 WuWa（2026-11-07 決定）。

## 繁體中文（台灣）

**App 名稱**（13 字）

```
喚取卡池分析 for 鳴潮
```

**簡短說明**

```
非官方工具。分析鳴潮喚取紀錄：保底進度、出金統計、5★ 時間軸，資料都存在你的手機。
```

**完整說明**

```
※ 本 App 為玩家自製的非官方工具，與庫洛遊戲（Kuro Games）無關。

讀取你的鳴潮喚取紀錄，一開啟各種數據清清楚楚，不用再手動計算。

【讀取方式】
・無線偵錯：透過 Android 內建的「無線偵錯」讀取鳴潮的記錄檔，自動取得喚取紀錄網址。第一次需要配對，之後按「更新資料」就會自動完成，讀完立刻中斷連線並關閉無線偵錯。
・root：已 root 的裝置可以直接讀取。
・Android 10 以下：可以直接讀取記錄檔。
・手動輸入：貼上喚取紀錄網址，或選擇 Client.log 檔案。

【功能】
・涵蓋 12 種卡池
・總抽數、5★／4★／3★ 件數與占比
・5★ 與 4★ 保底進度與剩餘抽數
・各卡池與整體的平均出金抽數
・5★ 時間軸與 5★ 總覽
・歷史紀錄表格：排序、搜尋、篩選
・物品圖示與角色、武器詳情
・一鍵產生分享圖，可遮罩 UID
・多帳號管理
・匯出／匯入 JSON，可匯入 WuWa Tracker 的資料
・選擇性的雲端同步：連結你自己的 Google 帳號，備份到你自己的 Google 雲端硬碟，並在手機與電腦之間同步
・深色／淺色主題、多國語言

【隱私】
・喚取紀錄只存在你的裝置上，開發者沒有伺服器，也不會收到你的任何資料。
・沒有廣告，沒有分析追蹤。
・原始碼公開：https://github.com/GoneTone/wuthering-waves-convene-gacha-analyzer

【協助翻譯】
https://crowdin.com/project/wuthering-waves-convene-gacha-analyzer
```

Unofficial Wuthering Waves convene history analyzer. Your data stays on device.
```

```
※ This is an unofficial fan-made tool. It is not affiliated with Kuro Games.

Read your Wuthering Waves convene history and see every stat at a glance, with no manual counting.

[How it reads your history]
• Wireless debugging: uses Android's built-in Wireless debugging to read the game's log file and find the convene history URL. Pair once; after that, tap "Update" and it is done automatically. The app disconnects and turns wireless debugging off right after reading.

• Android 10 and below: the log file can be read directly.
• Manual: paste the convene history URL, or choose a Client.log file.

• Optional cloud sync: link your own Google account to back up to your own Google Drive and sync between phone and PC
• Dark/light theme, many languages

[Privacy]
• Your convene history stays on your device. The developer runs no server and receives none of your data.

## 日本語

**アプリ名**（11 文字）

```
集音分析 for 鳴潮
```

**簡単な説明**

```
非公式ツール。鳴潮の集音履歴を分析。天井の進捗や★5 統計など、データは端末内に保存。
```

**詳しい説明**

```
※ 本アプリはプレイヤーが制作した非公式ツールであり、Kuro Games とは関係ありません。

鳴潮の集音履歴を読み込み、各種データをひと目で確認できます。手作業での計算は不要です。

【読み込み方法】
・ワイヤレスデバッグ：Android 標準の「ワイヤレスデバッグ」で鳴潮のログファイルを読み取り、集音履歴の URL を自動で取得します。初回のみペア設定が必要で、以降は「データを更新」を押すだけです。読み取り後はすぐに接続を切り、ワイヤレスデバッグをオフにします。
・root：root 化した端末では直接読み取れます。
・Android 10 以下：ログファイルを直接読み取れます。
・手動入力：集音履歴の URL を貼り付けるか、Client.log ファイルを選択します。

【機能】
・12 種類の集音に対応
・総回数、★5／★4／★3 の件数と割合
・★5 と ★4 の天井の進捗と残り回数
・集音ごと・全体の平均★5 獲得回数
・★5 タイムラインと ★5 一覧
・履歴テーブル（並べ替え、検索、絞り込み）
・アイテムアイコン、キャラクター・武器の詳細
・ワンタップで共有画像を作成（UID マスク可）
・複数アカウント管理
・JSON のエクスポート／インポート（WuWa Tracker のデータにも対応）
・任意のクラウド同期：ご自身の Google アカウントを連携すると、ご自身の Google ドライブにバックアップし、スマートフォンと PC の間で同期
・ダーク／ライトテーマ、多言語対応

【プライバシー】
・集音履歴は端末内にのみ保存されます。開発者はサーバーを持たず、データを受け取ることはありません。
・広告なし、分析ツールなし。
・オープンソース：https://github.com/GoneTone/wuthering-waves-convene-gacha-analyzer

【翻訳にご協力ください】
https://crowdin.com/project/wuthering-waves-convene-gacha-analyzer
```
